# STweaks

PowerShell WPF utility for Windows 10 and Windows 11. The preview opens from an elevated Windows PowerShell session without a desktop installer.

The current Scan covers Essential Tweaks. Review its findings before applying selected changes from Tweaks. A verified restore point is required before changes.

The upstream project is [Chris Titus Tech WinUtil](https://github.com/ChrisTitusTech/winutil); this repository publishes Salem's STweaks preview. See `LICENSE` for source licensing.

A compiled script is published by the **STweaks PowerShell preview** workflow as a GitHub Release asset. See [launch instructions](docs/STWEAKS-POWERSHELL.md).
